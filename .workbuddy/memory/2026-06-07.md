## 2026-06-07

### 17:40 — 添加 Netlify 部署支持

新增 Netlify 作为第三部署平台，与 Cloudflare Pages、Vercel 并列。

**新增文件：**
- `netlify.toml` — Netlify 构建设置 + SPA 回退 + API 路由透传
- `netlify/functions/api.ts` — Netlify Functions V2 入口，复用 `functions/api/src/` 下的加密/请求/API 模块

**关键设计：**
- Netlify Functions 运行在 Node.js 环境，使用 Hono 框架
- 通过相对路径 `../../functions/api/src/...` 复用现有 API 代码，零重复
- `netlify.toml` 配置：`/api/*` → `/.netlify/functions/api/:splat`（200 状态码，避免重定向）
- SPA 回退：`/*` → `/index.html`（200 状态码）

**README 更新：**
- 添加 Netlify 一键部署按钮（`https://app.netlify.com/start/deploy?repository=...`）
- 平台对比表格增加 Netlify 列
- 三平台版本对比表（Cloudflare / Vercel / Netlify）
- 项目结构添加 `netlify/functions/api.ts`
- 技术栈添加 Netlify Functions 条目

**部署方式：**
1. 点击 README 中的 "Deploy to Netlify" 按钮
2. 或访问 Netlify Dashboard → Add new site → Import from Git → 选择仓库
3. 构建命令：`npm install && npm run build:web`
4. 发布目录：`dist`
5. Functions 目录：`netlify/functions`（自动识别）
